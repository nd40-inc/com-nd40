How MANTA works

People stay on judgment and direction. Agents execute across every discipline in parallel with strict review and merge gates.

01 / DIRECT

Humans lead

Human leads define product vision, scope, architecture, acceptance criteria, and release sign-off. Work starts only when the definition of done is clear.

02 / EXECUTE

Parallel agent teams

Specialized engineering, server, economy, art, and QA agents work concurrently in isolated worktrees. Each deliverable breaks down into verified, testable changes.

03 / DELIVER

Automated delivery

Testing, independent review, integration, and release checks run automatically end to end. Only verified work reaches production, ready for human sign-off.
